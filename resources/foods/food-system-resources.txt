Fiche Mémo : Système de Ressources « Aliment »
Objectif : centraliser les propriétés des aliments. Un aliment est agnostique de son usage : le menu ou RestaurantData décide de ce qui est disponible.

Créer un aliment : dossier ressources/aliments > clic droit > Nouvelle ressource > FoodData > nommer (ex : pain.tres) > remplir l’Inspecteur.

FoodData

Identité : name, sprite (64x64)
Économie : price
Placement : type (FoodType, détermine l’emplacement au comptoir et quelles propriétés de PreparationData s’appliquent)
Délais : preparation_time (manipulation, hors cuisson)
Restrictions : tags (ex : &"caffeinated"), pour filtrer selon client/emplacement
Préparation : preparation (jamais null, vide par défaut)

PreparationData est répertorié dans good_preparation_data.

FoodType est répertorié dans game_enums.
